# ISP — Itmo Schedule Parser

Браузерное расширение (Chrome, Manifest V3), которое получает расписание
через API личного кабинета ИТМО (`my.itmo.ru`) и экспортирует его в файл
`.ics` для импорта в Google Calendar.

## Как это работает

1. На странице расписания в правом верхнем углу календаря появляется кнопка
   **«Экспорт»**.
2. По нажатию расширение одним запросом получает расписание через API
   от сегодняшней даты до даты через 5 календарных месяцев включительно.
   Если в конечном месяце нет такого дня, берётся его последний день.
   Календарь остаётся на месте; экспорт работает в видах «Неделя» и «Месяц».
   При ошибке API или ожидании ответа дольше 30 секунд экспорт прерывается,
   чтобы не скачать неполное расписание.
3. Перед скачиванием показывается окно предпросмотра: сколько найдено занятий и
   предметов, запрошенный период и список предметов — можно
   подтвердить экспорт или отменить.
4. После подтверждения занятия группируются по (предмет, день недели, время),
   интервал (еженедельно / раз в две недели) определяется по реальным датам, и
   формируется файл `itmo-schedule.ics`.

Экспортируются только будущие занятия (начиная с сегодняшнего дня). Каждое
сочетание (предмет, день, время) — отдельное событие с правилом повторения,
поэтому отдельные пары легко удалять в календаре.

## Данные и авторизация

Расширение обращается только к
`https://my.itmo.ru/api/schedule/schedule/personal` с параметрами `date_start`
и `date_end`. Для каждого запроса используется текущий Bearer-токен
`auth._token.itmoId` из `localStorage` сайта. Расширение не сохраняет токены,
не использует refresh-токен и не передаёт данные третьим лицам.
Если сессия недоступна, обновите страницу или войдите в личный кабинет заново.
Подробности ошибки доступны в подсказке кнопки «Экспорт» и консоли браузера.
В консоли также видны этапы экспорта с префиксом `[ITMO export]`: загрузка
расписания, предпросмотр, отмена и запуск скачивания. Журнал действий содержит
только названия этапов и счётчики, без токенов и содержимого расписания.

В этой версии изменён только источник расписания: экспортируются дата,
название предмета и время начала. Хотя API также возвращает время окончания,
преподавателя и аудиторию, формат `.ics` пока прежний: длительность пары —
90 минут, дополнительные поля не экспортируются.

Подход к API и авторизации основан на
[S-txt/my.itmo-schedule-exporter](https://github.com/S-txt/my.itmo-schedule-exporter).

# Проверка в реальном браузере

## Шаг 1. Соберите расширение

В терминале, в папке проекта:

```bash
npm install   # если ещё не делали
npm run build
npm test      # необязательно: проверка генерации .ics
```

После этого появится папка `dist/` с расширением: `content.js`, `manifest.json`
и папка `icons/`. Именно её Chrome будет загружать.

## Шаг 2. Загрузите расширение в Chrome

1. Откройте `chrome://extensions` (вставьте в адресную строку).
2. Включите переключатель **Developer mode** (Режим разработчика) — справа вверху.
3. Нажмите **Load unpacked** (Загрузить распакованное).
4. Выберите папку `dist/` (не корень проекта, а именно `dist/`).
5. Расширение появится в списке. Убедитесь, что у него нет красной надписи об ошибке.

## Шаг 3. Откройте расписание

1. Зайдите на `my.itmo.ru` и авторизуйтесь.
2. Перейдите в раздел **Расписание**.
3. Можно использовать любой вид календаря: **«Неделя»** или **«Месяц»**.
4. В правом верхнем углу календаря должна появиться синяя кнопка
   **«Экспорт»**.

> Если кнопки нет — подождите 1–2 секунды (она добавляется по таймеру) или
> обновите страницу.

## Шаг 4. Запустите экспорт

1. Нажмите кнопку **«Экспорт»**.
2. На кнопке будет видно `Загрузка…`; календарь не переключается.
3. После загрузки появится прежнее окно предпросмотра: `Нашёл N занятий, M предметов`,
   `Период: YYYY-MM-DD — YYYY-MM-DD` и список предметов.
4. Нажмите **«Скачать .ics»**, чтобы сохранить файл `itmo-schedule.ics`, или
   **«Отмена»**, чтобы ничего не скачивать.
5. После скачивания на кнопке появится `Готово: N занятий`
   (или `Экспорт отменён`, если вы закрыли окно).

## Шаг 5. Проверьте сам файл `.ics`

Прежде чем заливать в Google Calendar, откройте скачанный файл в текстовом
редакторе и проверьте глазами:

- **Названия предметов** (`SUMMARY:`) читаются нормально, без «кракозябр».
- **Даты и время** (`DTSTART:`) совпадают с тем, что в расписании.
- **Повторения** (`RRULE:` или `RDATE:`) выглядят разумно — например,
  `FREQ=WEEKLY;INTERVAL=2` для пар раз в две недели.

## Шаг 6. Импортируйте в Google Calendar

1. Откройте [calendar.google.com](https://calendar.google.com).
2. **Настройки (шестерёнка) → Settings → Import & export → Import**.
3. Выберите файл `itmo-schedule.ics`, укажите календарь и нажмите **Import**.
4. Проверьте, что события встали на правильные дни и время.

> Совет: для первого раза импортируйте в **отдельный/тестовый календарь**, чтобы
> при ошибке легко всё удалить, не задев основной.
